# Uber Trip Analysis — Power BI

Interactive Power BI portfolio project for analyzing Uber trip activity, booking value, trip distance, duration, ride patterns, payment methods, vehicle categories, and pickup/drop-off locations.

## Project Overview

This project presents a multi-page Power BI dashboard designed to explore Uber trip data from an operational and business perspective. The report combines KPI tracking, time-based analysis, location analysis, and detailed ride-level exploration.

## Dashboard Pages

### 1. Overview Dashboard
Provides a high-level summary of trip performance and key business metrics.

Key KPIs include:
- Total Bookings
- Total Booking Value
- Total Trip Distance
- Average Trip Distance
- Average Trip Time
- Farthest Trip
- Most Frequent Pickup Location
- Most Frequent Drop-off Location

The page also includes breakdowns by payment type, day/night travel, vehicle category, and location.

### 2. Time Analysis
Analyzes booking activity across time dimensions to identify demand patterns.

Includes analysis by:
- Pickup hour
- Day of week
- Date
- Pickup location

### 3. Details
Provides a detailed trip-level view for deeper exploration and validation.

Fields include:
- Pickup and drop-off dates
- Pickup and drop-off locations
- Pickup and drop-off times
- Vehicle type
- Payment type
- Passenger count
- Booking value
- Trip distance

## Business Questions Explored

- How many Uber trips were booked?
- What was the total booking value?
- What were the average trip distance and duration?
- Which pickup and drop-off locations were most frequently used?
- How did booking demand vary by hour and day of week?
- Which vehicle categories and payment methods were most common?
- How did daytime and nighttime trip patterns compare?

## Portfolio Highlights

- Built a 3-page interactive Power BI report focused on executive overview, time analysis, and detailed trip exploration.
- Created KPI measures using DAX for booking, revenue, distance, duration, and location-based performance.
- Added interactive filtering and dynamic visual analysis for vehicle type, payment method, time, and location.
- Structured the dashboard to translate ride-level data into clear business insights.
